# Student Performance Analysis

## Project Overview

This project analyzes a student performance dataset to identify factors associated with exam performance and placement outcomes.

## Research Question

What factors are associated with student exam performance and placement outcomes?

The analysis examines study hours, attendance, previous scores, sleep hours, internet usage, assignments completed, and placement status.

## Dataset

The dataset contains 10,000 student records and includes:

- Study hours
- Attendance
- Sleep hours
- Internet usage
- Assignments completed
- Previous score
- Exam score
- Placement status

## Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- GitHub

## Analysis

The data was analyzed using PivotTables to calculate averages and compare different groups. Charts were created to visualize patterns between student characteristics and exam scores.

## Key Findings

- Students who studied more hours tended to have higher exam scores.
- Students who completed more assignments tended to have higher exam scores.
- Higher attendance was associated with higher average exam scores.
- Higher previous scores were associated with higher exam scores.
- Sleep hours showed a positive association with exam performance.
- Higher internet usage was generally associated with lower exam scores.
- Placed students had substantially higher average exam scores, study hours, previous scores, and attendance than students who were not placed.

## Limitation

These findings show relationships and patterns in the dataset but do not prove that one factor directly causes another. Other factors may also influence student performance and placement outcomes.
